# Rockfire: Starter Trio Art Prompts
Phoenix · Unicorn · Mothman. **28 prompts per creature:** 1 reference lineup + 27 game images (3 eggs + 8 poses × baby/teen/adult).

## How to use (read once)
1. **One ChatGPT chat per creature.** Run the **reference lineup** prompt first. When you like it, keep it: every later image matches it.
2. **For each game image:** paste the prompt and **attach two images**: (a) that creature's lineup, (b) the matching **dragon** image from the repo's `art/` folder (e.g. `art/teen-run.png`). Then add this line: *"Match the character design of image 1 and the pose, size and framing of image 2."* This is the biggest consistency boost there is, and it keeps every creature the same size in the game.
3. **If the background comes back white or checkered**, reply: *"Same image, transparent background."*
4. **Save each one with the exact file name shown**, in a folder per creature: `art/phoenix/`, `art/unicorn/`, `art/mothman/` (e.g. `art/phoenix/teen-run.png`). The reference goes in as `reference.png`.
5. **Check every image before saving:** whole body in frame (nothing cut off at the edges), only one character, and the outfit matches its stage.

**Shared, no new art needed:** bed, bone, food, backgrounds, game art, and wardrobe pieces (hats/glasses get re-fitted per creature in code).
